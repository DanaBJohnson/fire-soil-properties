# fire-soil-properties

Scripts for analyzing data associated with manuscript on fire effects on soil properties. 
 
### Figures_fire_and_soil_properties.Rmd
R markdown file that renders all figures and SI figures for the manuscript. Statistical tests are including with the script. 

### Data availability
Data available on ESS DIVE Archive 
https://doi.org/10.15485/2438579
https://data.ess-dive.lbl.gov/view/doi%3A10.15485%2F2438579
